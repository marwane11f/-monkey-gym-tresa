# Build & Run

## Prerequisites
- Node.js 18+

## Install
```
npm install
```

## Run
```
node server.js
```
Site runs at http://localhost:3000

## Admin
/admin/login.html — credentials: `admin` / `vertex2024`

## Data Files
- `data/content.json`: services, gallery, images, contact info
- `data/bookings.json`: member bookings
- `data/members.json`: registered members
- `data/newsletter.json`: newsletter subscribers
